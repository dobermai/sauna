# Maintainers Guide

## Release Process

### Prerequisites

1. Install cargo-release:
   ```bash
   cargo install cargo-release
   ```

2. Ensure `CARGO_REGISTRY_TOKEN` secret is configured in GitHub repository settings:
   - Go to https://github.com/dobermai/sauna/settings/secrets/actions
   - Add secret with your [crates.io API token](https://crates.io/settings/tokens)

### Creating a Release

Run one of the following commands depending on the type of release:

```bash
cargo release patch  # 0.1.0 -> 0.1.1 (bug fixes)
cargo release minor  # 0.1.0 -> 0.2.0 (new features)
cargo release major  # 0.1.0 -> 1.0.0 (breaking changes)
```

This automatically:
1. Bumps the version in `Cargo.toml`
2. Creates a commit "Release vX.Y.Z"
3. Creates a git tag `vX.Y.Z`
4. Pushes commit and tag to GitHub

GitHub Actions then:
1. Runs tests (format, clippy, build, test)
2. Verifies the tag matches `Cargo.toml` version
3. Publishes `klafs-api` to crates.io
4. Builds `sauna` CLI binaries for all platforms
5. Creates a GitHub Release with binaries attached

### Dry Run

Dry-run is the default. To preview what will happen:

```bash
cargo release patch
```

To actually execute the release:

```bash
cargo release patch --execute
```

### What Gets Published

**crates.io**: Both `klafs-api` (library) and `sauna` (CLI) are published.

**GitHub Releases**: The `sauna` CLI binaries are built for:

| Platform | Binary |
|----------|--------|
| Linux x86_64 | `sauna-linux-x86_64` |
| Linux ARM64 | `sauna-linux-aarch64` |
| macOS x86_64 | `sauna-macos-x86_64` |
| macOS ARM64 (Apple Silicon) | `sauna-macos-aarch64` |
| Windows x86_64 | `sauna-windows-x86_64.exe` |

### Release Notes

Release notes are auto-generated by GitHub based on commits and merged PRs since the last tag. To customize grouping, add a `.github/release.yml` configuration file.

### Homebrew

The release workflow automatically updates the [homebrew-tap](https://github.com/dobermai/homebrew-tap) repository with the new version and SHA256 checksums.

Users install via:
```bash
brew install dobermai/tap/sauna
```
